# Contributing

Thank you for your interest in this learning project.

This repository is primarily maintained as a personal development exercise. Suggestions, corrections, and small improvements are welcome, but there is no commitment to review or merge external contributions.

## Before contributing

1. Open an issue describing the proposed change or problem.
2. Keep changes focused on the project's educational goals and current stage.
3. Avoid adding frameworks or infrastructure that are not needed for the learning objectives.
4. Never commit credentials, tokens, or personal data.

## Pull requests

- Use a descriptive branch name, such as `docs/clarify-routing` or `fix/consumer-output`.
- Explain what changed, why it changed, and how you validated it manually.
- Update documentation when behavior changes.
- Keep pull requests small and easy to review.

## Code style

Prefer readable Python, meaningful names, and simple explanations over unnecessary abstractions. For now, manual validation is sufficient for the project's learning scope.

Please also follow the [Code of Conduct](CODE_OF_CONDUCT.md).
