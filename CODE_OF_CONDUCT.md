# Code of Conduct

## Our commitment

We aim to keep project discussions respectful, welcoming, and focused on constructive learning.

## Expected behavior

- Communicate respectfully and assume good intent.
- Give specific, constructive feedback.
- Welcome questions and different experience levels.
- Respect privacy and avoid sharing other people's personal information.

## Unacceptable behavior

Harassment, discriminatory remarks, threats, personal attacks, and deliberate disruption are not acceptable.

## Scope and enforcement

These expectations apply to repository issues, pull requests, and other project spaces. The repository maintainer may edit or remove inappropriate content and restrict participation when necessary.

To report a concern, use a private contact method published by the maintainer, if available. Do not post sensitive reports publicly. This document does not guarantee a formal response time.
